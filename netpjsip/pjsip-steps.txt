  Tu build actual (2.10-dev msvc-19.2.7) tiene 6 versiones de atraso. La 2.16 trae soporte nativo de OpenSSL 3.x y opcionalmente Windows Schannel (TLS sin OpenSSL).

  ---
  Paso 1: Instalar OpenSSL

  - Descargar Win64 OpenSSL (versión full, NO la "Light") desde slproweb
  - Instalar en C:\OpenSSL-Win64
  - Elegir "Copy DLLs to OpenSSL binaries directory"

  Alternativa sin OpenSSL: pjsip >= 2.15 soporta Schannel (TLS nativo de Windows), lo cual elimina la dependencia de OpenSSL completamente.

  Paso 2: Instalar SWIG

  - Descargar SwigWin 4.4.1 de sourceforge
  - Extraer a C:\swigwin-4.4.1
  - Agregar al PATH del sistema

  Paso 3: Clonar pjproject

  git clone https://github.com/pjsip/pjproject.git
  cd pjproject
  git checkout 2.16

  Paso 4: Crear config_site.h

  Crear el archivo pjlib/include/pj/config_site.h:

  #ifndef __PJ_CONFIG_SITE_H__
  #define __PJ_CONFIG_SITE_H__

  /* TLS/SSL Support */
  #define PJ_HAS_SSL_SOCK 1

  /* Opción A: OpenSSL (default) */
  /* Opción B: Schannel nativo (descomentar la siguiente línea) */
  /* #define PJ_SSL_SOCK_IMP PJ_SSL_SOCK_IMP_SCHANNEL */

  /* DLL Export (requerido para C# wrapper) */
  #define PJ_EXPORT_SPECIFIER  __declspec(dllexport)
  #define PJ_IMPORT_SPECIFIER  __declspec(dllimport)
  #define PJ_DLL 1
  #ifdef _LIB
  #define PJ_EXPORTING 1
  #endif

  #endif

  Sin PJ_DLL + PJ_EXPORT_SPECIFIER, el DLL no exporta símbolos y C# tira EntryPointNotFoundException.

  Paso 5: Compilar pjsip en Visual Studio

  1. Abrir pjproject-vs14.sln en VS 2022 — aceptar upgrade de projects
  2. Configuración: Release-Dynamic | x64 (usa /MD, compatible con .NET)
  3. Agregar paths de OpenSSL en el property sheet build/vs/pjproject-vs14-common-config.props:
    - Include: C:\OpenSSL-Win64\include
    - Library: C:\OpenSSL-Win64\lib
  4. Build > Build Solution (Ctrl+Shift+B)
  5. Los .lib salen a la carpeta lib/

  Paso 6: Generar wrapper C# con SWIG

  cd pjproject\pjsip-apps\src\swig\csharp

  swig -I"..\..\..\..\pjlib\include" ^
       -I"..\..\..\..\pjlib-util\include" ^
       -I"..\..\..\..\pjmedia\include" ^
       -I"..\..\..\..\pjsip\include" ^
       -I"..\..\..\..\pjnath\include" ^
       -w312 -c++ -csharp ^
       -o pjsua2_wrap.cpp ^
       "..\pjsua2.i"

  Esto genera:
  - pjsua2_wrap.cpp — bridge C++ a P/Invoke
  - Muchos .cs — clases C# (Account, Call, Endpoint, etc.) con [DllImport("pjsua2")]

  Paso 7: Compilar el DLL nativo (pjsua2.dll)

  1. Agregar un nuevo proyecto C++ DLL a la solución, nombre: pjsua2_dll
  2. Agregar pjsua2_wrap.cpp y pjsua2_wrap.h
  3. Configurar:
    - Configuration Type: Dynamic Library (.dll)
    - Target Name: pjsua2
    - Runtime Library: /MD (Multi-threaded DLL)
    - Include dirs: todos los includes de pjsip + C:\OpenSSL-Win64\include
    - Library dirs: lib/ de pjproject + C:\OpenSSL-Win64\lib
    - Linker deps: libpjproject-*.lib, ws2_32.lib, Iphlpapi.lib, dsound.lib, dxguid.lib, netapi32.lib, mswsock.lib, ole32.lib, user32.lib, gdi32.lib, advapi32.lib
  4. Build → produce pjsua2.dll

  Paso 8: Compilar el assembly C# (pj.dll)

  1. Crear proyecto C# Class Library (.NET 10 o Standard 2.0)
  2. Copiar todos los .cs generados por SWIG (excepto sample.cs)
  3. Build → produce pj.dll

  Paso 9: Deployment

  TekiumSoftphoneWPF.exe
  pj.dll                    ← managed C# wrapper
  pjsua2.dll                ← native x64 DLL
  libssl-3-x64.dll          ← OpenSSL runtime (solo si usas OpenSSL)
  libcrypto-3-x64.dll       ← OpenSSL runtime (solo si usas OpenSSL)

  Si usas Schannel en vez de OpenSSL, no necesitas los DLLs de OpenSSL.

  ┌─────────────────────────────┬──────────────────────────────────┬─────────────────────────────────────────────────────────┐
  │          Problema           │              Causa               │                        Solución                         │
  ├─────────────────────────────┼──────────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ PJSIP_EUNSUPTRANSPORT       │ PJ_HAS_SSL_SOCK no está en 1     │ Verificar config_site.h                                 │
  ├─────────────────────────────┼──────────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ CRT mismatch / crashes      │ Mezcla de /MT y /MD              │ Todo en Release-Dynamic (/MD)                           │
  ├─────────────────────────────┼──────────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ EntryPointNotFoundException │ DLL no exporta símbolos          │ Agregar PJ_DLL=1 + export specifiers                    │
  ├─────────────────────────────┼──────────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ No encuentra OpenSSL DLLs   │ DLLs no están en PATH ni en bin/ │ Copiar libssl-3-x64.dll y libcrypto-3-x64.dll al output │
  ├─────────────────────────────┼──────────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Link errors con OpenSSL     │ Nombres de lib viejos            │ pjsip 2.16 maneja ambos nombres automáticamente         │
